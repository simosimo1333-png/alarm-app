# 「Human: Fall Flat」風オリジナルゲーム 設計資料(リサーチまとめ)

> 目的: No Brakes Games「Human: Fall Flat」(以下 HFF)の**操作感・雰囲気**を参考に、模倣ではないオリジナルゲームを設計するための事実情報集。
> 収集したのは著作権保護対象外の「アイデア・事実・メカニクスの記述」のみ。コード・モデル・テクスチャ・音声・長文引用は含まない。
> 数値はほぼ公開されていないため、「実装指針」の数値は動画・レビュー記述から逆算した**目安値**であり、自作ゲームでの初期値+チューニング前提とする。

## 1. キャラクター(HFFでは「ボブ」)の見た目と動き

### 事実情報
- ボブは「特徴のない、ミニマルな全身白色の人間」。公式ビジュアルでは白いボディに野球帽(キャップ)姿が標準。顔のディテールはほぼ無い。
- 比喩として「人間に対するゼリー」= 形は人間だが全身がぐにゃぐにゃ(wobbly mess)と紹介される。
- 体型はやや太めの寸胴プロポーション。頭は丸く大きめ、胴体は樽型、腕・脚は太めの円筒状。指の造形はなく手はミトン状。
- カスタマイズ: 部位ごと(頭・上半身・下半身)に色を塗れる/体にペイント(お絵かき)できる/多数のコスチューム(作業員、忍者、シェフ、騎士など)を着せられる。オンラインで未カスタマイズだと白いまま。
- 移動: 歩くたびに足・腕・頭が慣性で揺れる。加速が遅く、一歩一歩が大げさでふらふらした千鳥足。
- 腕の挙動: **カメラの上下(ピッチ)と連動して、つかみ状態の腕が上下する**。上を見ながらつかみボタンを押すと腕を頭上に伸ばし、下を見ると腕が下がる。これが「高い縁をつかむ→下を向いて前進しながら体を引き上げる」というよじ登りの基本操作になっている。
- つかみ: 左右の手が独立していて、それぞれ「触れているものを何でも握る」。壁・レバー・箱・ロープ・他プレイヤーまで対象。
- よじ登り: 片手ずつ交互に高い所へ掛け替え、体を左右にスイングして勢いをつけて登るテクニックが成立する(= 手は単なるフラグでなく物理ジョイント)。
- 落下時: 落ちている間・着地直後はラグドール化して脱力し、地面に倒れて一瞬動かない。少し経つと「意識を取り戻す」ように外力で引き起こされ、立ち上がる。

### 実装指針(目安)
- キャラは 6〜9 剛体の簡易アクティブラグドール(頭 / 胴上 / 胴下 / 左右上腕+前腕 or 腕1本ずつ / 左右脚)+ 各関節にモーター。完全ラグドールではなく「立とうとする力(胴と頭に上向きトルク/バネ)」を常時かける。
- 身長目安 1.7〜1.8m 相当。頭は身長の約 1/5 と大きめ、腕は太い円筒、手先は球でよい(見た目はミトン)。
- デフォルト色: オフホワイト(#F2F0EB 程度)+ワンポイント(帽子など)。カスタマイズは「部位ごとの単色変更」から始めるのが安価で雰囲気が出る。
- 腕の目標角度 = カメラピッチに 1:1 で追従(可動域: 下 -30°〜頭上 +170° 程度)。つかみボタン押下中のみ腕を前方に伸ばす。腕はバネジョイントで目標角へ追従させ、硬さを弱めにして「遅れてついてくる」感を出す。
- 手の実装: 手先の球が物体に接触中につかみ入力があれば、その点に拘束(point-to-point / lock constraint)を生成。離す=拘束削除。壁面でもつかめるようにする(静的メッシュにも拘束可)。
- 落下: 接地を失って一定速度以上で落下したら立位維持トルクをオフ→着地後 0.5〜1.0 秒脱力→トルク復帰で起き上がり。

## 2. 操作方法

### PC版(マウス+キーボード)— 事実情報
| 入力 | 動作 |
|---|---|
| W / A / S / D | 移動 |
| マウス移動 | カメラ(視点)+頭と腕の向き。上下で腕の高さ |
| 左クリック(押しっぱなし) | **左手**でつかむ |
| 右クリック(押しっぱなし) | **右手**でつかむ |
| Space | ジャンプ(ジャンプ中は体が脱力気味になる) |
- よじ登りの定石:「上を見て両ボタン長押し→縁を掴んだら下を見て前進」で体が持ち上がる。
- ゲームパッドでは左スティック=移動、右スティック=カメラ、LT/RT=左右の手、が標準(移動と腕の向きが同系統の入力を共有する設計)。

### モバイル版(Codeglue 開発 / 505 Games、2019-06-26 リリース)— 事実情報
- 画面左: **仮想スティック**で移動。
- 画面の空き領域を**スワイプ**してカメラ回転。
- 画面右: **ジャンプボタン**と**つかむ(GRAB)ボタン**。
- 腕操作は**専用の腕ジョイスティック**方式: 水平軸で「どちらの腕を出すか(左/右/両方)」、垂直軸で「腕の高さ」を制御。トグル(押すたび掴む/離す)要素も残している。
- 直感操作の補助: 画面上のキャラ自体をタッチ&ドラッグすると、片腕・両腕でつかんでそのまま動かせる。挙がっている腕をタップすると離す。
- モバイルは最大 4 人マルチプレイ対応。レベルは段階的に追加配信(Laboratory, Golf, City, Thermal, Factory, Steam, Ice など)。

### 実装指針(目安)
- Web版PC操作は HFF と同配置(WASD+マウス視点+左右クリック=左右手+Space)をそのまま踏襲してよい(操作割り当て自体はアイデアなので流用可)。Pointer Lock 必須。
- モバイルWeb: 左下に移動スティック、右下に「JUMP」「GRAB」の2ボタン、右半面ドラッグでカメラ。GRAB は「押しっぱなし=両手つかみ」を基本にし、慣れたユーザー向けに GRAB ボタンを上下ドラッグ→腕の高さ、左右ドラッグ→左手/右手選択、の腕スティック化を第2段階で足す。
- 「掴んだ腕をタップで離す」「キャラ直接ドラッグ」は独自性を保ちつつ再現価値が高い(HFFモバイルの発明だが、UI手法はアイデアレベル)。

## 3. カメラ

### 事実情報
- 三人称の追従オービットカメラ。マウス/右スティック/スワイプで360°回転+上下ピッチ。
- カメラの上下がそのまま腕の高さ・頭の向きに直結する(=カメラは「視点」であると同時に「腕コントローラ」)。
- キャラが倒れても・ラグドール化してもカメラはキャラ(胴体)を追い続ける。壁越しは自動でめり込み回避。
- PC版には隠しのFPSモードやシアターモード切替ショートカットがあるが、標準プレイは常に三人称。

### 実装指針(目安)
- ピボット: キャラの胸〜頭(地上高 ~1.4m)。距離 3.5〜4.5m、標準ピッチ約 -10〜-15°(やや見下ろし)。FOV 50〜60°。
- 追従: 位置は指数スムージング(遅延 0.1〜0.2 秒)で、ラグドールの細かい揺れを拾いすぎないようにローパスをかける。回転はプレイヤー入力のみ(自動回り込みなし)。
- ピッチ可動域: -60°(見下ろし)〜+70°(見上げ)。この値をそのまま腕の目標高さへマッピング。
- 壁めり込み: ピボット→カメラ間をレイキャスト/スフィアキャストし、遮蔽時は距離を詰める。

## 4. グラフィック/アートスタイル

### 事実情報
- ローポリ+単色フラットな面で構成されたミニマル造形。テクスチャよりマテリアル単色(または大きな面ごとの塗り分け)が支配的。
- 色調はソフトで彩度低めのパステル寄り(木=明るいベージュ、石=ライトグレー、差し色に赤・青のガジェット類)。
- ライティングは柔らかい太陽光+淡いアンビエント、影はソフトシャドウ。全体に「おもちゃ/ジオラマ」感。
- 世界観: **各レベルはボブの夢**。レベル全体が空中(虚空)に浮かぶ島のような構造で、縁から落ちると空へ落下する。背景は淡いグラデーションの空と雲のみで地平線に大地がない。
- 導入はナレーション(夢の解説)付き。UI は最小限: HUD ほぼ無し、メニューはシンプルな白/淡色パネルと控えめなタイポグラフィ、ユーモアのあるトーン。

### 実装指針(目安)
- three.js では `MeshLambertMaterial`/`MeshToonMaterial` 単色+`DirectionalLight`(強度~1.0、暖色寄り #FFF4E0)+`HemisphereLight`(空色→地面色)で近い質感になる。PBRテクスチャは使わない方が「らしい」。
- 影: PCF ソフトシャドウ、シャドウマップ 2048。輪郭を出すため陰影コントラストは弱めに。
- 背景: 空グラデーション(上 #87B8E8 → 地平線 #E8F0F8 程度)+ビルボードまたはローポリの雲を数個。フォグ(遠距離で空色に溶ける)を入れ、レベルの「浮遊島」の縁の下は何も置かない。
- レベルの床の裏側・側面もモデリング(下から見えるため)。土の断面色(茶系)にすると浮島感が出る。
- UI: 白ベース・角丸・大きめ余白・1フォント。HUDは基本非表示、チュートリアルは世界内の看板やナレーション字幕で。

## 5. レベル一覧とテーマ・代表ギミック

### 事実情報(ベースゲーム、リリース順)
1. **Mansion(邸宅)** — チュートリアル。腕の使い方・物のつかみ方を教える。ギミック: ボタンで開くドア、押して開ける扉、箱運び。
2. **Train(列車)** — 駅と貨物列車。ジャンプと「物理で物を動かす」ことを教える。ギミック: 台車・ワゴン、レバーでのポイント切替、線路上の障害物、瓦礫運び。
3. **Carry(運搬)** — 運ぶことがテーマ。箱と**床スイッチ(重みで作動)**を導入。ギミック: 木箱を載せて扉を開ける、シーソー的な重量パズル、投石機(カタパルト)での射出。
4. **Mountain(山)** — 岩山の大空間。純粋なプラットフォーミング試験場。ギミック: 崖のよじ登り、ロープ、ウィンチ/リフト、丸太、落ちたら大きく戻される高低差。
5. **Demolition(解体)** — 工事現場。ギミック: **鉄球(レッキングボール)**に飛びついて振り子移動、操作盤で重機を旋回させ壁を壊す、レバー操作のショベル、消火器で窓を割る、壊せる壁。
6. **Castle(城)** — 中世の城。ギミック: **跳ね橋**(カタパルトで自分を飛ばして橋を掴み引き下ろす)、投石機、巻き上げ機(ウィンチ)と歯車、鎖、城門。
7. **Water(水)** — 湖と船。**乗り物(操縦)**を導入。ギミック: 手漕ぎボート(オールを物理で漕ぐ)、スピードボート、貨物船、ダム決壊、水車、いかだ、水流。
8. **Power Plant(発電所)** — 工業施設。**電気パズル**を導入。ギミック: ケーブル(ワイヤー)を端子に抜き差しして通電、ショートさせる遊び、ファン、コンベア、感電要素、リモコン式の装置。
9. **Aztec(遺跡)** — 石造遺跡。初期の最終レベルで最長。ギミック: 転がる巨石、床の仕掛け(トラップ)、棒を組んで橋を作る、精密ジャンプ、重りパズル、神殿の最上部がゴール。
10. **Dark(暗闇)** — 夜の幻想的な鉱山/城。ギミック: 光源(たいまつ)運び、トロッコ、石炭を炉にくべて**鋳造で鍵を作る**、歯車、暗所ナビゲーション。

### DLC/追加レベル(テーマ名のみ、無料アップデートで追加)
Steam(蒸気機関)、Ice(氷雪)、Thermal(温泉/地熱)、Factory(工場・コンベアと歯車と炎)、Golf(ゴルフ場)、City(街)、Forest(森)、Laboratory(研究所・最短)、Lumber(製材所)、Red Rock(峡谷)、Tower(塔)、Miniature(ミニチュア)、Copper World(銅の世界)、Port / Underwater / Dockyard など。ワークショップ(ユーザー製レベル)も多数。

### 実装指針
- オリジナル版では「チュートリアル(室内・ドアとボタン)→ 物運び(箱+床スイッチ)→ 登山(よじ登り+ロープ)→ 機械(レバー+ウィンチ+壊せる壁)→ 水(ボート)」の 5 レベル構成が HFF の学習曲線をなぞれる。
- ギミックの実装優先度(HFFの頻出順): ①押しボタン/床スイッチ+ドア ②木箱(持つ/積む) ③レバー ④ロープ・鎖(distance constraint の連結) ⑤跳ね橋・シーソー(hinge) ⑥ウィンチ/カタパルト(motor付きhinge) ⑦壊せる壁(閾値超の衝撃で破片化) ⑧ボート(浮力+オール) ⑨電気ケーブル(両端ソケット判定)。
- 各レベルは 5〜15 分で踏破できる規模、常に複数解(正攻法と力技)を許す設計が HFF らしさの核。

## 6. 物理・ゲームフィール

### 事実情報
- 歩行は遅く、加速がゆっくりで「もっさり」。走る概念はなく常に同じテンポ。歩くと脚・腕・頭が慣性で揺れる。
- ジャンプは低め(膝〜腰程度の段差を越えられる程度)。ジャンプ中は体が脱力し、着地でよろける。
- 物をつかむと自分の質量と相手の質量が相互に影響する: 重い物を引きずると自分が遅くなり、逆に固定物をつかめば自分の体を引っ張れる。
- 鉄球やロープにぶら下がると振り子として体重が乗り、スイングして勢いをつけられる。
- 高所から落ちてもダメージ・死亡は無い。**レベル外(縁の外)に落ちると、直前のチェックポイント付近の空から降ってきて着地する**のがリスポーン演出。メニューからチェックポイント再読込も可能。
- パズルに必要なアイテムがレベル外へ落ちた場合は自動で復活(リスポーン)する。
- チェックポイントは通過型で、マルチでは誰か1人が踏めば全員分有効。

### 実装指針(目安)
- 歩行速度: 最高 2.5〜3.5 m/s、加速に 0.4〜0.6 秒かける(即最高速にしない)。旋回も速度依存でゆっくり。
- ジャンプ初速: 上方向 4〜5 m/s(到達高さ約 0.8〜1.2m)。ジャンプ中は姿勢維持トルクを 30〜50% に減衰させ「ふにゃっ」と飛ばせる。
- 質量目安: キャラ全身 ~70kg、木箱 20〜40kg、家具 50kg+。摩擦は高め(引きずり感)。物理は 60Hz 固定ステップ+サブステップで安定させる。
- つかみ拘束はやや柔らかく(バネ的に)して、重量物との綱引きで腕が伸びる感じを出す。
- 落下リスポーン: レベル底面に kill 平面(y < -20 など)。トリガーしたら最後のチェックポイントの上空 8〜12m にラグドール状態でスポーンして落とす(この「空から降ってくる」演出が世界観と直結)。
- アイテムにも kill 平面→初期位置リスポーンを実装。
- チェックポイント: 見えないトリガーボリューム。踏んだら無音か控えめな演出(HFFはUI通知をほぼ出さない)。

## 7. マルチプレイ

### 事実情報
- ローカル(画面分割): 2人。
- オンライン: 最大 **8人**(PC/コンソール)。ホストがロビー(公開/非公開)を作る方式。
- モバイル版: 最大 **4人**のオンラインマルチ。
- 協力プレイの実態: 全員が同じレベル空間で自由に動く。役割分担(1人がレバーを保持、他が通過)、人間ピラミッド、相手をつかんで投げる/引き上げる、といった創発的な協力・妨害が主な魅力。チェックポイントは1人が踏めば全員有効で、テンポを保つ。
- 人数が増えるほどカオスになるパーティゲーム性が強い。

### 実装指針
- Web版はまず 1 人+同室2人(1台のPCでキーボード+ゲームパッド)が現実的。オンラインは WebSocket/WebRTC で 2〜4 人から。物理同期はホスト権威(ホストが全剛体をシミュレートし、他は入力送信+補間)が HFF 型ゲームでは実装しやすい。
- 「プレイヤー同士をつかめる」ことは協力プレイの面白さの核なので、手の拘束対象に他プレイヤーの剛体を必ず含める。
- チェックポイント共有(誰か1人でOK)を踏襲する。
